## Q1. 문제 — 주차 요금 정산

`fees=[기본시간,기본요금,단위시간,단위요금]`, 기록은 `"HH:MM 차량번호 IN|OUT"`입니다. 누적 주차 시간이 기본 시간을 넘으면 초과 시간을 단위 시간으로 올림해 요금을 더합니다. 출차 기록이 없는 차량은 23:59 출차로 처리합니다. 차량번호 오름차순 요금을 return 하세요.

- 기록 최대 100,000개, 하루 안의 올바른 입·출차 순서
- 예: `fees=[60,1000,30,500]`, `records=["10:00 12 IN","11:00 34 IN","11:30 12 OUT"]` → `[1500,13000]`

## Q1. 정답

```python
from collections import defaultdict

def solution(fees, records):
    def minutes(text):
        hour, minute = map(int, text.split(':'))
        return hour * 60 + minute

    entered = {}
    total = defaultdict(int)
    for record in records:
        time, car, action = record.split()
        if action == 'IN':
            entered[car] = minutes(time)
        else:
            total[car] += minutes(time) - entered.pop(car)
    for car, start in entered.items():
        total[car] += 23 * 60 + 59 - start

    base_time, base_fee, unit_time, unit_fee = fees
    answer = []
    for car in sorted(total):
        parked = total[car]
        fee = base_fee
        if parked > base_time:
            fee += ((parked - base_time + unit_time - 1) // unit_time) * unit_fee
        answer.append(fee)
    return answer
```

## Q1. 해설

시간을 분으로 통일하고 차량별 입차 시각과 누적 시간을 분리합니다. 요금 올림은 정수식으로 처리합니다.

- 시간복잡도 `O(R + C log C)`
- 반례: 여러 번 입·출차한 차량과 정확히 기본 시간만 주차한 차량

## Q2. 문제 — 폴더 권한 상속

`parents[i]`는 i번 폴더의 부모이며 루트는 하나이고 값은 -1입니다. 권한 `[folder,user]`는 해당 폴더와 모든 자손 폴더에 적용됩니다. 각 `[folder,user]` 질의의 접근 가능 여부를 순서대로 return 하세요.

- 폴더·권한·질의 각각 최대 200,000개
- 예: `parents=[-1,0,0,1]`, `grants=[[0,"a"],[1,"b"]]`, `queries=[[3,"a"],[2,"b"],[3,"b"]]` → `[True,False,True]`

## Q2. 정답

```python
from collections import defaultdict
from bisect import bisect_right

def solution(parents, grants, queries):
    n = len(parents)
    children = [[] for _ in range(n)]
    root = 0
    for node, parent in enumerate(parents):
        if parent == -1: root = node
        else: children[parent].append(node)

    tin = [0] * n; tout = [0] * n; timer = 0
    stack = [(root, 0)]
    while stack:
        node, state = stack.pop()
        if state == 0:
            tin[node] = timer; timer += 1
            stack.append((node, 1))
            for child in reversed(children[node]): stack.append((child, 0))
        else:
            tout[node] = timer - 1

    by_user = defaultdict(list)
    for folder, user in grants:
        by_user[user].append((tin[folder], tout[folder]))

    merged = {}
    for user, intervals in by_user.items():
        intervals.sort(); compact = []
        for left, right in intervals:
            if compact and left <= compact[-1][1] + 1:
                compact[-1][1] = max(compact[-1][1], right)
            else:
                compact.append([left, right])
        merged[user] = compact

    answer = []
    for folder, user in queries:
        intervals = merged.get(user, [])
        index = bisect_right(intervals, [tin[folder], 10**30]) - 1
        answer.append(index >= 0 and intervals[index][1] >= tin[folder])
    return answer
```

## Q2. 해설

DFS 방문 순서에서 한 폴더의 모든 자손은 연속 구간 `[tin,tout]`입니다. 사용자별 권한 구간을 합친 뒤 질의 폴더의 진입 시각을 포함하는 구간이 있는지 이분 탐색합니다.

- 시간복잡도 `O((N+G+Q) log G)`
- 반례: 조상과 자손에 같은 사용자의 권한이 중복 부여된 경우

## Q3. 문제 — 재고 이벤트 처리

초기 재고 `stock=[[상품,수량]]`, 이벤트는 `[시각,상품,"IN"|"OUT",수량]`입니다. 같은 시각에는 IN을 모두 먼저 처리하고, OUT은 입력 순서대로 처리합니다. OUT 시 재고가 부족하면 해당 이벤트 전체가 실패하며 재고는 변하지 않습니다. `[상품별 최종 재고 목록, 실패 횟수]`를 return 하세요. 재고 목록은 상품명 오름차순입니다.

- 상품·이벤트 최대 200,000개
- 예: `stock=[["A",3]]`, `events=[[1,"A","OUT",4],[1,"A","IN",2]]` → `[[["A",1]],0]`

## Q3. 정답

```python
def solution(stock, events):
    inventory = dict(stock)
    ordered = sorted(enumerate(events), key=lambda x: (x[1][0], x[1][2] == 'OUT', x[0]))
    failed = 0
    for _, (_, product, action, amount) in ordered:
        inventory.setdefault(product, 0)
        if action == 'IN': inventory[product] += amount
        elif inventory[product] >= amount: inventory[product] -= amount
        else: failed += 1
    remaining = [[product, inventory[product]] for product in sorted(inventory)]
    return [remaining, failed]
```

## Q3. 해설

정렬 키에 시각, IN 우선 여부, 원래 입력 인덱스를 넣어 규칙을 그대로 구현합니다.

- 시간복잡도 `O(E log E)`
- 반례: 실패한 OUT이 재고를 0으로 만들지 않아야 합니다.

## Q4. 문제 — 우선 배송 스케줄

n개 도시와 양방향 도로 `[u,v,time]`, 요청 `[요청시각,출발,도착,중요도]`가 있습니다. 배송원은 1번 도시에서 시작합니다. 비어 있을 때까지 도착한 요청 중 중요도가 높은 것, 동점이면 입력 순서가 빠른 것을 선택합니다. 현재 도시에서 출발지로 이동한 뒤 목적지로 이동하며 중간 요청으로 작업을 바꾸지 않습니다. 요청별 완료 시각을 입력 순서로 return 하세요. 이동 불가능한 요청은 없습니다.

- `n≤500`, 도로≤5,000, 요청≤20,000
- 예: `n=3`, `roads=[[1,2,2],[2,3,2]]`, `requests=[[0,1,3,1],[1,2,3,5]]` → `[4,8]`

## Q4. 정답

```python
import heapq

def solution(n, roads, requests):
    graph = [[] for _ in range(n + 1)]
    for u, v, cost in roads:
        graph[u].append((v, cost)); graph[v].append((u, cost))

    all_dist = []
    for start in range(n + 1):
        dist = [10**30] * (n + 1); dist[start] = 0
        heap = [(0, start)]
        while heap:
            cost, node = heapq.heappop(heap)
            if cost != dist[node]: continue
            for nxt, edge in graph[node]:
                new = cost + edge
                if new < dist[nxt]:
                    dist[nxt] = new; heapq.heappush(heap, (new, nxt))
        all_dist.append(dist)

    waiting = []; answer = [0] * len(requests)
    index = time = 0; location = 1
    while index < len(requests) or waiting:
        if not waiting and time < requests[index][0]: time = requests[index][0]
        while index < len(requests) and requests[index][0] <= time:
            _, start, end, priority = requests[index]
            heapq.heappush(waiting, (-priority, index, start, end)); index += 1
        _, request_index, start, end = heapq.heappop(waiting)
        time += all_dist[location][start] + all_dist[start][end]
        location = end; answer[request_index] = time
    return answer
```

## Q4. 해설

도시 수가 500 이하이므로 각 도시에서 다익스트라를 수행해 반복 이동 거리를 전처리합니다. 요청은 최대 힙 효과를 위해 중요도에 음수를 붙입니다.

- 시간복잡도 `O(V(E log V)+R log R)`
- 반례: 배송 중 도착한 고중요도 요청은 현재 배송을 중단시키지 않습니다.
