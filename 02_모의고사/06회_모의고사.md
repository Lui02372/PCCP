## Q1. 문제 — 계단 신호

0번 칸에서 출발해 한 번에 1칸 또는 2칸 이동하여 정확히 n번 칸에 도착하려 합니다. 이동 순서가 다르면 다른 방법입니다. 방법 수를 `1,000,000,007`로 나눈 나머지를 return 하세요.

- `1 ≤ n ≤ 1,000,000`
- 예: `n=4` → `5`

## Q1. 정답

```python
def solution(n):
    mod = 1_000_000_007
    one_back, current = 1, 1  # dp[0], dp[1]
    for _ in range(2, n + 1):
        one_back, current = current, (one_back + current) % mod
    return current
```

## Q1. 해설

n번 칸의 마지막 이동은 n-1에서 1칸 오거나 n-2에서 2칸 오는 두 경우뿐이므로 `dp[n]=dp[n-1]+dp[n-2]`입니다.

- 시간복잡도 `O(n)`, 공간복잡도 `O(1)`
- 반례: n=1은 1가지이며 반복문이 실행되지 않습니다.

## Q2. 문제 — 연속하지 않는 광고 선택

시간순 광고 후보의 수익 `money`가 주어집니다. 인접한 두 광고는 같은 화면 구간을 점유하므로 함께 선택할 수 없습니다. 광고를 하나도 선택하지 않아도 될 때 최대 수익을 return 하세요.

- `1 ≤ len(money) ≤ 300,000`
- `-10^9 ≤ money[i] ≤ 10^9`
- 예: `[5,-1,4,10,-3,7]` → `22`

## Q2. 정답

```python
def solution(money):
    skip_prev = 0
    best_prev = 0
    for profit in money:
        skip_prev, best_prev = best_prev, max(best_prev, skip_prev + profit)
    return best_prev
```

## Q2. 해설

현재 광고를 고르면 직전 광고는 고를 수 없으므로 두 칸 전 최적값에 현재 수익을 더합니다. 고르지 않으면 직전까지의 최적값을 유지합니다.

- 시간복잡도 `O(N)`, 공간복잡도 `O(1)`
- 반례: 모든 수익이 음수면 0을 반환합니다.
- 정확성 근거: 최적해의 마지막 광고는 선택되거나 선택되지 않는 두 경우로 완전히 분할됩니다.

## Q3. 문제 — 장애물 경로 수

`board`에서 0은 이동 가능한 칸, 1은 장애물입니다. `(0,0)`에서 출발해 오른쪽 또는 아래로만 이동하여 `(R-1,C-1)`에 도착하는 경로 수를 `1,000,000,007`로 나눈 값을 return 하세요.

- `1 ≤ R,C ≤ 1,000`
- 시작점이나 도착점이 장애물이면 0을 return 합니다.
- 예: `[[0,0,0],[0,1,0],[0,0,0]]` → `2`

## Q3. 정답

```python
def solution(board):
    rows, cols = len(board), len(board[0])
    if board[0][0] or board[-1][-1]:
        return 0
    mod = 1_000_000_007
    dp = [0] * cols
    dp[0] = 1
    for r in range(rows):
        for c in range(cols):
            if board[r][c] == 1:
                dp[c] = 0
            elif c > 0:
                dp[c] = (dp[c] + dp[c - 1]) % mod
    return dp[-1]
```

## Q3. 해설

현재 칸에 오는 경로는 위와 왼쪽에서 오는 경로의 합입니다. 한 행 배열에서 갱신 전 `dp[c]`는 위쪽 값, 갱신된 `dp[c-1]`은 왼쪽 값입니다.

- 시간복잡도 `O(RC)`, 공간복잡도 `O(C)`
- 반례: 첫 행 또는 첫 열 중간의 장애물 뒤쪽 경로 수는 0이 되어야 합니다.

## Q4. 문제 — 휴식 일정 최적화

n일 동안 매일 A 또는 B 휴식 중 정확히 하나를 선택합니다. i일에 A를 선택한 피로 변화는 `a[i]`, B는 `b[i]`입니다. 같은 종류를 3일 연속 선택할 수 없습니다. 총 피로 변화의 최솟값을 return 하세요.

- `1 ≤ n ≤ 200,000`, `len(a)=len(b)=n`
- `-10^9 ≤ a[i],b[i] ≤ 10^9`
- 예: `a=[1,100,1], b=[2,2,2]` → `4`

## Q4. 정답

```python
def solution(a, b):
    inf = 10**30
    # A 1연속, A 2연속, B 1연속, B 2연속
    states = [a[0], inf, b[0], inf]
    for day in range(1, len(a)):
        a1, a2, b1, b2 = states
        states = [min(b1, b2) + a[day], a1 + a[day],
                  min(a1, a2) + b[day], b1 + b[day]]
    return min(states)
```

## Q4. 해설

미래 선택 가능 여부는 직전 선택 종류와 연속 횟수만 알면 결정됩니다. 네 상태만 유지해 날짜별로 전이합니다.

- 시간복잡도 `O(N)`, 공간복잡도 `O(1)`
- 반례: n=1에서는 2연속 상태가 무한대로 남지만 최솟값에는 영향을 주지 않습니다.
- 정확성 근거: 규칙을 만족하는 모든 일정은 네 상태 중 정확히 하나로 끝나며, 각 전이는 허용된 직전 상태를 모두 비교합니다.

| 문항 | 반드시 확인할 초기값 | 숨은 테스트 | 목표 복잡도 |
|---|---|---|---|
| Q1 | `dp[0]=1`, `dp[1]=1` | n=1, 큰 n의 모듈러 | `O(N)` |
| Q2 | 아무것도 선택하지 않은 값 0 | 전부 음수, 길이 1 | `O(N)` |
| Q3 | 시작 칸 1, 장애물 0 | 시작·도착 장애물, 한 행 | `O(RC)` |

Q4는 값이 음수여도 최솟값 DP가 정상 작동해야 합니다. 고정 폭 정수 언어에서는 누적 피로와 INF를 64비트로 둡니다.
