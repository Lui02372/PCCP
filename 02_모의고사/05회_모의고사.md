## Q1. 문제 — 보안키 후보 생성

보안 장치는 서로 다른 숫자가 담긴 `digits`에서 정확히 3개를 골라 세 자리 보안키를 만듭니다. 같은 숫자는 한 번만 사용할 수 있고, 첫 자리는 0일 수 없습니다. 세 자리의 합이 `target`인 서로 다른 보안키의 개수를 return 하도록 `solution(digits, target)`을 완성하세요.

### 제한사항

- `3 ≤ len(digits) ≤ 10`
- `digits`의 원소는 0 이상 9 이하이며 서로 다릅니다.
- `0 ≤ target ≤ 27`

### 입출력 예

| digits | target | result |
|---|---:|---:|
| `[0,1,2,3]` | `6` | `6` |
| `[1,2,3]` | `5` | `0` |

첫 예시에서 가능한 보안키는 `123`, `132`, `213`, `231`, `312`, `321`의 6개입니다.

## Q1. 정답

```python
from itertools import permutations

def solution(digits, target):
    answer = 0
    for selected in permutations(digits, 3):
        if selected[0] != 0 and sum(selected) == target:
            answer += 1
    return answer
```

## Q1. 해설

최대 10개 중 3개를 순서 있게 고르는 경우는 `10P3=720`개뿐입니다. 각 순열에서 선행 0과 자리 합을 확인하면 됩니다.

- 시간복잡도: `O(N³)`
- 핵심 반례: `[0,1,2]`, target 3에서는 `102`, `120`, `201`, `210`만 가능합니다.
- 정확성 근거: 모든 길이 3 순열을 정확히 한 번 열거하므로 조건을 만족하는 모든 보안키를 빠짐없이 한 번씩 셉니다.

## Q2. 문제 — 균형 팀 편성

짝수 명의 직원 능력치가 `ability`에 주어집니다. 정확히 절반을 A팀으로, 나머지를 B팀으로 배정합니다. 두 팀 능력치 합 차이의 절댓값을 최소화한 값을 return 하세요. 팀원의 순서는 의미가 없습니다.

### 제한사항

- `2 ≤ len(ability) ≤ 20`, 길이는 짝수
- `1 ≤ ability[i] ≤ 10,000`

### 입출력 예

| ability | result |
|---|---:|
| `[1,3,4,9]` | `3` |
| `[5,5]` | `0` |

첫 예시에서 A팀을 `[1,9]`, B팀을 `[3,4]`로 구성하면 합이 10과 7이므로 차이는 3이며 이것이 최솟값입니다.

## Q2. 정답

```python
from itertools import combinations

def solution(ability):
    total = sum(ability)
    team_size = len(ability) // 2
    answer = float('inf')
    for team in combinations(ability, team_size):
        answer = min(answer, abs(total - 2 * sum(team)))
    return answer
```

## Q2. 해설

A팀 합이 `selected`라면 B팀 합은 `total-selected`이고 차이는 `|total-2×selected|`입니다. 정확히 절반을 고르는 모든 조합만 확인합니다.

- 시간복잡도: `O(C(N,N/2)×N)`
- 핵심 반례: 같은 능력치가 여러 명 있어도 직원은 서로 다른 사람이며 조합 선택에는 문제가 없습니다.
- 정확성 근거: 가능한 모든 A팀 구성을 열거하면 각 팀 분할은 A/B가 뒤바뀐 형태까지 포함해 반드시 검사됩니다.

## Q3. 문제 — 두 단계 생산 일정

각 제품은 준비 공정과 가공 공정을 차례로 거칩니다. `tasks[i]=[prepare, process]`는 i번 제품의 준비·가공 시간입니다. 준비 담당자와 가공 담당자는 각각 한 명이며, 서로 다른 제품을 동시에 작업할 수 있습니다. 준비 담당자가 정한 제품 순서와 같은 순서로 가공해야 합니다. 모든 제품을 끝내는 최소 시각을 return 하세요.

### 제한사항

- `1 ≤ len(tasks) ≤ 8`
- 각 시간은 1 이상 100 이하
- 시각 0에 두 담당자는 비어 있습니다.

### 입출력 예

| tasks | result |
|---|---:|
| `[[3,5],[1,10],[2,2]]` | `18` |

## Q3. 정답

```python
from itertools import permutations

def solution(tasks):
    answer = float('inf')
    for order in permutations(tasks):
        prepare_end = 0
        process_end = 0
        for prepare, process in order:
            prepare_end += prepare
            process_end = max(process_end, prepare_end) + process
        answer = min(answer, process_end)
    return answer
```

## Q3. 해설

순서가 정해지면 준비 완료 시각은 누적 합입니다. 가공은 해당 제품 준비가 끝나고 가공 담당자가 비는 시각 중 늦은 시각부터 시작합니다.

- 시간복잡도: `O(N!×N)`
- 핵심 반례: 준비가 빨리 끝나도 이전 제품 가공이 끝나지 않았다면 기다려야 합니다.
- 정확성 근거: N이 8 이하이므로 모든 제품 순서를 검사하며, 각 순서의 완료 시각은 공정 규칙에 따라 유일하게 계산됩니다.

## Q4. 문제 — 기능 장비 최소 비용

필요 기능 문자열 `required`와 장비 목록 `kits`가 주어집니다. `kits[i]=[features,cost]`이며 장비 하나를 최대 한 번 선택할 수 있습니다. 선택 장비들의 기능 합집합이 모든 필요 기능을 포함하도록 하는 최소 비용을 return 하세요. 불가능하면 `-1`을 return 합니다.

필요하지 않은 기능이 장비에 포함되어 있어도 선택할 수 있습니다.

### 제한사항

- `1 ≤ len(required) ≤ 15`, 문자는 서로 다른 영소문자
- `1 ≤ len(kits) ≤ 100`
- 기능 문자열에는 영소문자가 중복 없이 들어 있습니다.
- `1 ≤ cost ≤ 10^9`

### 입출력 예

| required | kits | result |
|---|---|---:|
| `"abc"` | `[["ab",5],["bc",6],["c",2]]` | `7` |
| `"ab"` | `[["a",3],["c",1]]` | `-1` |

## Q4. 정답

```python
def solution(required, kits):
    index = {feature: i for i, feature in enumerate(required)}
    full = (1 << len(required)) - 1
    inf = 10**30
    dp = [inf] * (full + 1)
    dp[0] = 0

    for features, cost in kits:
        kit_mask = 0
        for feature in features:
            if feature in index:
                kit_mask |= 1 << index[feature]
        next_dp = dp[:]
        for mask in range(full + 1):
            combined = mask | kit_mask
            next_dp[combined] = min(next_dp[combined], dp[mask] + cost)
        dp = next_dp

    return -1 if dp[full] == inf else dp[full]
```

## Q4. 해설

필요 기능 15개를 비트로 표현하면 가능한 확보 상태는 최대 `2^15`개입니다. 장비를 하나씩 보며 선택하지 않는 상태와 선택하는 상태를 모두 유지합니다.

- 시간복잡도: `O(K×2^M)`, M은 필요 기능 수
- 공간복잡도: `O(2^M)`
- 핵심 반례: 한 장비가 필요 기능을 하나도 제공하지 않거나, 이미 확보한 기능만 제공할 수 있습니다.
- 정확성 근거: i번째 장비 처리 후 DP는 앞의 i개 장비로 각 기능 상태를 만드는 최소 비용이라는 불변식을 유지합니다.
