## Q1. 문제 — 회전 드론

드론은 `(0, 0)`에서 북쪽을 보고 시작합니다. 명령 `L`, `R`은 각각 왼쪽·오른쪽으로 90도 회전하고, `F`는 바라보는 방향으로 한 칸 전진합니다. 모든 명령 후 좌표 `[x, y]`를 return 하세요. 북쪽 이동은 y가 1 증가합니다.

- `1 ≤ len(commands) ≤ 1,000,000`
- `commands`는 `L`, `R`, `F`로만 이루어진 문자열입니다.
- 이동 가능한 좌표에 제한은 없으며 음수 좌표도 정상적인 결과입니다.
- 예: `"FFRFFLFF"` → `[2, 4]`

### 예시 추적과 채점 포인트

`FFRFFLFF`는 `(0,0) → (0,1) → (0,2) → 동쪽 회전 → (1,2) → (2,2) → 북쪽 회전 → (2,3) → (2,4)` 순서로 실행됩니다. 왼쪽 회전 후 방향 인덱스가 음수가 되는 경우와 명령 100만 개를 모두 검증합니다.

## Q1. 정답

```python
def solution(commands):
    directions = [(0, 1), (1, 0), (0, -1), (-1, 0)]
    direction = x = y = 0
    for command in commands:
        if command == "L":
            direction = (direction - 1) % 4
        elif command == "R":
            direction = (direction + 1) % 4
        else:
            dx, dy = directions[direction]
            x, y = x + dx, y + dy
    return [x, y]
```

## Q1. 해설

방향을 문자열로 바꾸지 않고 0~3 인덱스로 관리하면 회전은 모듈러 연산 한 번입니다.

- 시간복잡도: `O(len(commands))`
- 반례: 처음 명령이 `L`일 때도 음수 방향 인덱스가 정상 처리되어야 합니다.

## Q2. 문제 — 안전 구역 수

`computers[i][j]`가 1이면 i번과 j번 컴퓨터가 연결되어 있습니다. 직접 또는 다른 컴퓨터를 거쳐 연결되는 컴퓨터들은 같은 안전 구역입니다. 안전 구역 수를 return 하세요.

- `1 ≤ N ≤ 1,000`, 행렬은 대칭, 대각선은 1
- 예: `[[1,1,0],[1,1,0],[0,0,1]]` → `2`

### 명세 확인

- 간접 연결도 같은 구역입니다. 예를 들어 0-1, 1-2가 연결되면 0과 2도 같은 구역입니다.
- 다른 정점과 연결되지 않은 컴퓨터도 안전 구역 하나를 이룹니다.
- 입력 행렬은 수정하지 않습니다.

## Q2. 정답

```python
def solution(computers):
    n = len(computers)
    visited = [False] * n
    groups = 0

    for start in range(n):
        if visited[start]:
            continue
        groups += 1
        stack = [start]
        visited[start] = True
        while stack:
            current = stack.pop()
            for next_node, connected in enumerate(computers[current]):
                if connected and not visited[next_node]:
                    visited[next_node] = True
                    stack.append(next_node)
    return groups
```

## Q2. 해설

미방문 컴퓨터 하나에서 DFS를 시작하면 같은 연결 요소 전체를 방문합니다. DFS를 새로 시작한 횟수가 안전 구역 수입니다.

- 시간복잡도: 인접 행렬을 확인하므로 `O(N²)`
- 반례: 다른 컴퓨터와 전혀 연결되지 않은 컴퓨터도 하나의 구역입니다.

## Q3. 문제 — 동시 화재 확산

격자 `forest`에서 `F`는 불, `T`는 나무, `X`는 바위, `.`은 빈 땅입니다. 불은 매분 상하좌우의 나무로 동시에 번집니다. 모든 나무가 타는 최소 시간, 불가능하면 `-1`을 return 하세요.

- 행·열은 각각 최대 1,000, 불은 하나 이상 존재
- 예: `["FTTT"]` → `3`

### 세부 규칙

- `F`는 0분에 이미 불이 난 칸이며 나무 개수에 포함하지 않습니다.
- 불은 `T`에만 번지고 `X`, `.`을 통과하거나 밟고 지나가지 않습니다.
- 처음부터 `T`가 없으면 모든 나무가 이미 불탄 상태이므로 0을 return 합니다.
- 같은 분에 불이 붙는 여러 칸은 동시에 처리되어야 합니다.

예시에서는 오른쪽 나무들이 1분, 2분, 3분에 차례로 불탑니다. 바위·빈 땅에 의해 분리된 나무가 남으면 `-1`입니다.

## Q3. 정답

```python
from collections import deque

def solution(forest):
    rows, cols = len(forest), len(forest[0])
    board = [list(row) for row in forest]
    queue = deque()
    trees = 0
    for r in range(rows):
        for c in range(cols):
            if board[r][c] == "F":
                queue.append((r, c, 0))
            elif board[r][c] == "T":
                trees += 1

    answer = 0
    while queue:
        r, c, minute = queue.popleft()
        for dr, dc in ((-1, 0), (1, 0), (0, -1), (0, 1)):
            nr, nc = r + dr, c + dc
            if 0 <= nr < rows and 0 <= nc < cols and board[nr][nc] == "T":
                board[nr][nc] = "F"
                trees -= 1
                answer = minute + 1
                queue.append((nr, nc, minute + 1))
    return answer if trees == 0 else -1
```

## Q3. 해설

처음 불난 모든 칸을 큐에 넣는 다중 시작점 BFS입니다. 큐에서 먼저 꺼낸 경로가 해당 나무에 도달하는 최단 시간입니다.

- 시간복잡도: `O(R×C)`
- 반례: 나무가 바위로 완전히 막혀 있으면 끝까지 남아 `-1`입니다.

## Q4. 문제 — 출입 카드가 있는 미로

`maze`에는 시작 `S`, 도착 `E`, 벽 `#`, 빈 칸 `.`, 카드 `a`~`f`, 문 `A`~`F`가 있습니다. 카드를 밟으면 계속 보유하고, 대응하는 카드를 가진 경우에만 문을 통과합니다. 도착까지 최소 이동 횟수, 불가능하면 `-1`을 return 하세요.

- 행·열 최대 100, 카드 종류 최대 6개
- 예: `["S.a","##A","..E"]` → `4`

### 세부 규칙

- `S`와 `E`는 각각 정확히 하나입니다. 시작 시 보유 카드는 없습니다.
- 카드 칸을 밟으면 해당 카드를 영구히 보유합니다. 이미 가진 카드를 다시 밟아도 변화가 없습니다.
- 카드·문은 전혀 없을 수 있으며, 같은 좌표라도 보유 카드 조합이 다르면 다른 탐색 상태입니다.
- 예시는 `S → . → a → A → E`로 이동하므로 4회입니다.

### 채점 포인트

카드가 필요 없는 최단 경로, 카드를 얻으러 되돌아가야 하는 경로, 문에 막혀 도달 불가능한 경로, 같은 좌표를 다른 카드 상태로 재방문해야 하는 경로를 검증합니다.

## Q4. 정답

```python
from collections import deque

def solution(maze):
    rows, cols = len(maze), len(maze[0])
    for r in range(rows):
        for c in range(cols):
            if maze[r][c] == "S":
                start = (r, c)

    visited = [[[False] * 64 for _ in range(cols)] for _ in range(rows)]
    queue = deque([(start[0], start[1], 0, 0)])
    visited[start[0]][start[1]][0] = True

    while queue:
        r, c, cards, dist = queue.popleft()
        if maze[r][c] == "E":
            return dist
        for dr, dc in ((-1, 0), (1, 0), (0, -1), (0, 1)):
            nr, nc = r + dr, c + dc
            if not (0 <= nr < rows and 0 <= nc < cols):
                continue
            cell = maze[nr][nc]
            if cell == "#":
                continue
            next_cards = cards
            if 'a' <= cell <= 'f':
                next_cards |= 1 << (ord(cell) - ord('a'))
            if 'A' <= cell <= 'F' and not (cards & (1 << (ord(cell) - ord('A')))):
                continue
            if not visited[nr][nc][next_cards]:
                visited[nr][nc][next_cards] = True
                queue.append((nr, nc, next_cards, dist + 1))
    return -1
```

## Q4. 해설

같은 좌표라도 가진 카드가 다르면 통과할 수 있는 문이 달라집니다. 따라서 방문 상태는 좌표만이 아니라 `(행, 열, 카드 비트마스크)`로 구분해야 합니다.

- 시간복잡도: `O(R×C×2^6)`
- 반례: 카드를 얻기 전 방문한 문 앞 칸을, 카드 획득 후 다시 방문할 수 있어야 합니다.
