## Q1. 문제 — 버전 문자열 검증

유효한 버전은 `v주버전.부버전.패치버전` 형식입니다. 각 버전 번호는 숫자 1~3자리이며, 숫자 0 자체를 제외하면 0으로 시작할 수 없습니다. 공백과 부호는 허용하지 않습니다. `versions`에서 유효한 문자열 개수를 return 하세요.

- 최대 200,000개, 문자열 길이 최대 30
- 예: `["v1.0.12","v01.2.3","v1.2","x1.2.3"]` → `1`

## Q1. 정답

```python
def solution(versions):
    def valid(text):
        if not text.startswith('v'): return False
        parts = text[1:].split('.')
        if len(parts) != 3: return False
        for part in parts:
            if not (1 <= len(part) <= 3) or not part.isdigit(): return False
            if len(part) > 1 and part[0] == '0': return False
        return True
    return sum(valid(version) for version in versions)
```

## Q1. 해설

접두사, 점으로 나눈 토큰 수, 숫자 여부, 길이, 선행 0을 독립적으로 확인합니다.

- 시간복잡도: 전체 문자열 길이 합에 비례
- 반례: `v0.0.0`은 유효하지만 `v00.0.0`, `v1.+2.3`, `v1.2.3.4`는 무효입니다.

## Q2. 문제 — 목표 합 구간 수

정수 배열 `numbers`에서 합이 정확히 `k`인 비어 있지 않은 연속 부분배열의 개수를 return 하세요. 원소에는 음수와 0이 포함될 수 있습니다.

- `1≤N≤300,000`, 각 값과 k의 절댓값≤`10^9`
- 정답은 64비트 정수 범위
- 예: `[1,-1,1,-1,1]`, `k=1` → `6`

## Q2. 정답

```python
from collections import defaultdict

def solution(numbers, k):
    frequency = defaultdict(int); frequency[0] = 1
    prefix = answer = 0
    for number in numbers:
        prefix += number
        answer += frequency[prefix - k]
        frequency[prefix] += 1
    return answer
```

## Q2. 해설

현재 누적 합이 P일 때 과거 누적 합이 `P-k`인 위치마다 그 다음 칸부터 현재까지 합이 k인 구간 하나가 생깁니다.

- 시간복잡도 평균 `O(N)`
- 반례: k=0일 때 현재 누적 합을 세기 전에 과거 빈도를 조회해야 빈 구간을 세지 않습니다.

## Q3. 문제 — 벽 하나 제거하기

격자에는 시작 `S`, 도착 `E`, 벽 `#`, 빈 칸 `.`이 있습니다. 상하좌우로 이동하며, 전체 경로에서 벽 한 칸을 최대 한 번 제거하고 그 칸으로 이동할 수 있습니다. 최소 이동 횟수를 return 하고 불가능하면 `-1`을 return 하세요.

- 행·열 각각 최대 1,000, S와 E는 하나씩
- 예: `["S#E","..."]` → `2`

## Q3. 정답

```python
from collections import deque

def solution(board):
    rows, cols = len(board), len(board[0])
    for r in range(rows):
        for c in range(cols):
            if board[r][c] == 'S': start = (r, c)
    visited = [[[False, False] for _ in range(cols)] for _ in range(rows)]
    visited[start[0]][start[1]][0] = True
    queue = deque([(start[0], start[1], 0, 0)])
    while queue:
        r, c, broken, distance = queue.popleft()
        if board[r][c] == 'E': return distance
        for dr, dc in ((-1,0),(1,0),(0,-1),(0,1)):
            nr, nc = r + dr, c + dc
            if not (0 <= nr < rows and 0 <= nc < cols): continue
            next_broken = broken
            if board[nr][nc] == '#':
                if broken: continue
                next_broken = 1
            if not visited[nr][nc][next_broken]:
                visited[nr][nc][next_broken] = True
                queue.append((nr, nc, next_broken, distance + 1))
    return -1
```

## Q3. 해설

같은 좌표라도 벽 제거 기회가 남았는지에 따라 이후 가능 경로가 달라집니다. BFS 상태를 `(행,열,제거 여부)`로 둡니다.

- 시간복잡도 `O(RC)`, 공간복잡도 `O(RC)`
- 반례: 벽을 제거하지 않은 채 같은 칸에 늦게 도착하는 상태가 더 유리할 수 있습니다.

## Q4. 문제 — 공유기 설치 간격

서로 다른 집 좌표 `homes` 중 정확히 `routers`곳을 선택해 공유기를 설치합니다. 설치된 공유기 중 가장 가까운 두 공유기의 거리 최댓값을 return 하세요.

- `2≤N≤300,000`, 좌표 절댓값≤`10^9`, `2≤routers≤N`
- 예: `[1,2,8,4,9]`, routers=3 → `3`

## Q4. 정답

```python
def solution(homes, routers):
    homes.sort()
    left, right = 1, homes[-1] - homes[0]
    answer = 0
    while left <= right:
        distance = (left + right) // 2
        count = 1; last = homes[0]
        for home in homes[1:]:
            if home - last >= distance:
                count += 1; last = home
        if count >= routers:
            answer = distance; left = distance + 1
        else:
            right = distance - 1
    return answer
```

## Q4. 해설

최소 간격 d로 설치가 가능하면 d보다 작은 간격도 가능합니다. 판정할 때 첫 집부터 가능한 가장 왼쪽 집에 차례로 설치하면 설치 수를 최대화합니다.

- 시간복잡도 `O(N log 좌표범위)`
- 반례: routers=N이면 정렬 후 인접 좌표 차이의 최솟값이 답입니다.
- 정확성 근거: 그리디 설치 위치를 더 오른쪽으로 옮겨도 이후 설치 가능 공간은 늘어나지 않습니다.
