# PCCP 자격증 준비 폴더

프로그래머스 **PCCP(코딩전문역량인증)** 대비를 위한 학습·실전 모의고사 작업 공간입니다.

## 시작 순서

1. [00_PCCP_실제시험_유형과_학습운영계획.md](00_PCCP_실제시험_유형과_학습운영계획.md)에서 시험 형식과 학습 흐름을 확인합니다.
2. [01_모의고사_01~10회_설계서.md](01_모의고사_01~10회_설계서.md)에서 회차별 목적·문항 설계를 검토합니다.
3. 설계 승인 후 `02_모의고사/`에 각 회차를 단일 파일로 작성합니다. **문항 단위**로 `Q1 문제 → Q1 정답 → Q1 해설 → Q2 문제 → Q2 정답 → Q2 해설` 순서를 반복합니다.
4. 풀이 뒤 `03_오답노트/오답노트_템플릿.md`에 원인과 재풀이 계획을 남깁니다.

## 폴더 구성

| 경로 | 용도 |
|---|---|
| `00_시험정보/` | 공식 시험 형식, 언어별 입출력·문법 점검 |
| `01_학습로드맵/` | 유형별 학습 체크리스트와 주간 계획 |
| `02_모의고사/` | 승인 후 작성할 1~10회 실전 모의고사 |
| `03_오답노트/` | 회차·유형별 오답과 재풀이 기록 |
| `04_코드템플릿/` | 언어별 빠른 시작 템플릿과 알고리즘 스니펫 |
| `05_테스트케이스/` | 경계값·반례·성능 검증 케이스 |

> 저작권과 공정성을 위해 실제 PCCP 기출문제를 복제하지 않습니다. 공식 시험 형식과 공개 샘플의 문제 제시 방식에 맞춘 **독자 제작 모의문제**만 작성합니다.
