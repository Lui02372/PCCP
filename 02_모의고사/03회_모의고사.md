# PCCP 실전 모의고사 03회 — 자료구조 기반 처리

> 120분 · Q1 20분 / Q2 30분 / Q3 35분 / Q4 35분 · Python 함수형

# 문제

## Q1. 접힌 안내문 복원

문자열 `text`에서 괄호 안의 내용은 역순으로 읽습니다. 괄호는 올바르게 짝지어지고 중첩될 수 있습니다. 모든 괄호를 해석한 문자열을 return 하세요.

- `1 ≤ len(text) ≤ 200,000`, 소문자와 `(`, `)`만 포함
- 예: `"ab(cd(ef)g)h"` → `"abgfe dch"`에서 공백 없이 `"abgfedch"`

## Q2. 호출 센터 우선 대기열

`calls`의 원소 `[도착시각, 중요도, 처리시간]`이 도착시각 오름차순으로 주어집니다. 상담원은 한 명이며, 비어 있을 때 도착한 호출 중 중요도가 큰 것, 같으면 먼저 도착한 것을 처리합니다. 각 호출의 대기시간 합을 return 하세요.

- `1 ≤ calls ≤ 200,000`, 모든 값은 0 이상, 처리시간은 1 이상
- 예: `[[0,1,3],[1,5,2],[2,3,1]]` → `5`

## Q3. 중복 없는 신고 결과

`reports`의 원소는 `[신고자, 대상]`입니다. 같은 신고자가 같은 대상을 여러 번 신고해도 한 번만 인정됩니다. 신고 횟수가 `k` 이상인 대상이 제재되며, 제재 대상 신고자별로 받은 알림 수를 `users` 순서대로 return 하세요.

- `1 ≤ users, reports ≤ 200,000`
- 예: `users=["a","b","c"], reports=[["a","x"],["a","x"],["b","x"],["c","y"]], k=2` → `[1,1,0]`

## Q4. 평균 대기시간 최소화

`jobs`의 원소 `[요청시각, 소요시간]`이 주어집니다. 작업 하나만 처리하며, 현재까지 도착한 작업 중 소요시간이 짧은 것을 먼저 선택합니다. 모든 작업의 `(완료시각 - 요청시각)` 평균의 정수 부분을 return 하세요.

- `1 ≤ jobs ≤ 200,000`, 시각·소요시간은 0 이상, 소요시간은 1 이상
- 예: `[[0,3],[1,9],[2,6]]` → `9`

# 정답

| 문항 | 정답 알고리즘 | 복잡도 |
|---|---|---|
| Q1 | 여는 괄호마다 현재 버퍼를 스택에 저장하고 닫을 때 뒤집어 합침 | `O(N)` |
| Q2 | 도착 호출을 최대 힙으로 넣고 시각을 진행 | `O(N log N)` |
| Q3 | `(신고자, 대상)` 집합, 대상별 신고자 집합/횟수 | `O(R)` 평균 |
| Q4 | 현재 도착 작업을 최소 힙에 넣는 SJF 시뮬레이션 | `O(N log N)` |

# 해설

Q1은 문자열을 매번 뒤집어 붙이면 느릴 수 있으므로 문자 버퍼를 사용합니다. Q2와 Q4 모두 힙이 비었을 때 다음 도착시각으로 시간을 점프해야 합니다. Q2는 중요도 우선이라 최대 힙, Q4는 짧은 작업 우선이라 최소 힙입니다. Q3은 중복 제거를 제재 판정 전에 해야 합니다.

## Q1. 접힌 안내문
```python
def solution(text):
    stack = [[]]
    for ch in text:
        if ch == '(':
            stack.append([])
        elif ch == ')':
            stack[-2].extend(reversed(stack.pop()))
        else:
            stack[-1].append(ch)
    return ''.join(stack[0])
```
- 시간복잡도: `O(N)` · 반례: 중첩 괄호와 빈 괄호.

## Q2. 호출 센터 우선 대기열
```python
import heapq
def solution(calls):
    heap=[]; i=t=wait=0
    while i < len(calls) or heap:
        if not heap: t=max(t,calls[i][0])
        while i < len(calls) and calls[i][0] <= t:
            a,p,d=calls[i]; heapq.heappush(heap,(-p,a,i,d)); i+=1
        _,a,_,d=heapq.heappop(heap); wait+=t-a; t+=d
    return wait
```
- 시간복잡도: `O(N log N)` · 반례: 힙이 비는 유휴 시간.

## Q3. 중복 없는 신고 결과
```python
from collections import defaultdict
def solution(users, reports, k):
    unique=set(map(tuple,reports)); targets=defaultdict(set)
    for user,target in unique: targets[target].add(user)
    answer=defaultdict(int)
    for reporters in targets.values():
        if len(reporters) >= k:
            for user in reporters: answer[user]+=1
    return [answer[user] for user in users]
```
- 시간복잡도: 평균 `O(R)` · 반례: 같은 신고자의 중복 신고.

## Q4. 평균 대기시간 최소화
```python
import heapq
def solution(jobs):
    jobs.sort(); heap=[]; i=t=total=0
    while i < len(jobs) or heap:
        if not heap: t=max(t,jobs[i][0])
        while i < len(jobs) and jobs[i][0] <= t:
            a,d=jobs[i]; heapq.heappush(heap,(d,a)); i+=1
        d,a=heapq.heappop(heap); t+=d; total+=t-a
    return total // len(jobs)
```
- 시간복잡도: `O(N log N)` · 반례: 같은 요청시각의 작업은 소요시간이 짧은 것부터 처리합니다.
