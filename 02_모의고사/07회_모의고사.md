## Q1. 문제 — 배송 상자 묶기

상자 무게 `weights`가 주어집니다. 운반 묶음 하나에는 최대 2개를 담을 수 있고 합이 `limit` 이하여야 합니다. 모든 상자를 운반하는 최소 묶음 수를 return 하세요.

- `1 ≤ len(weights) ≤ 300,000`, `1 ≤ weights[i] ≤ limit`
- 예: `[70,50,80,50], 100` → `3`

## Q1. 정답

```python
def solution(weights, limit):
    weights.sort()
    left, right = 0, len(weights) - 1
    bundles = 0
    while left <= right:
        if left < right and weights[left] + weights[right] <= limit:
            left += 1
        right -= 1
        bundles += 1
    return bundles
```

## Q1. 해설

가장 무거운 상자는 반드시 현재 묶음에 들어갑니다. 가장 가벼운 상자와도 함께 못 담으면 다른 어떤 상자와도 못 담습니다. 함께 담을 수 있으면 가장 가벼운 상자를 붙여도 남은 문제를 악화시키지 않습니다.

- 시간복잡도 `O(N log N)`
- 반례: 상자가 하나 남은 경우 묶음 하나를 추가합니다.

## Q2. 문제 — 회의실 최대 사용

각 회의는 `[start,end]`이며 한 회의실에서 겹치지 않게 일부를 선택합니다. 한 회의의 종료 시각과 다음 회의 시작 시각이 같으면 연속 진행할 수 있습니다. 선택 가능한 최대 회의 수를 return 하세요.

- `1 ≤ len(meetings) ≤ 200,000`, `0 ≤ start < end ≤ 10^9`
- 예: `[[1,4],[2,3],[3,5],[5,6]]` → `3`

## Q2. 정답

```python
def solution(meetings):
    meetings.sort(key=lambda meeting: (meeting[1], meeting[0]))
    count = 0
    last_end = -1
    for start, end in meetings:
        if start >= last_end:
            count += 1
            last_end = end
    return count
```

## Q2. 해설

끝나는 시각이 가장 빠른 회의를 선택하면 이후 회의를 배치할 수 있는 시간이 최대가 됩니다. 동일 종료 시각에서는 어떤 회의를 택해도 이후 선택 가능성은 같습니다.

- 시간복잡도 `O(N log N)`
- 반례: `[1,2]` 다음 `[2,3]`은 선택할 수 있습니다.

## Q3. 문제 — 도로 할인권

1번부터 n번까지의 도시와 양방향 도로 `roads=[u,v,cost]`가 있습니다. `start`에서 `end`까지 이동하며, 도로 하나의 비용을 정확히 한 번 `cost//2`로 할인할 수 있습니다. 도착 가능한 최소 비용을 return 하고 불가능하면 `-1`을 return 하세요.

- `2 ≤ n ≤ 100,000`, `1 ≤ len(roads) ≤ 200,000`
- 비용은 1 이상 `10^9` 이하
- 여러 간선과 자기 루프가 존재할 수 있음
- 예: `n=3, roads=[[1,2,8],[2,3,8],[1,3,20]], start=1, end=3` → `10`

## Q3. 정답

```python
import heapq

def solution(n, roads, start, end):
    graph = [[] for _ in range(n + 1)]
    for u, v, cost in roads:
        graph[u].append((v, cost)); graph[v].append((u, cost))
    inf = 10**30
    dist = [[inf, inf] for _ in range(n + 1)]
    dist[start][0] = 0
    heap = [(0, start, 0)]
    while heap:
        cost, node, used = heapq.heappop(heap)
        if cost != dist[node][used]:
            continue
        for nxt, edge in graph[node]:
            normal = cost + edge
            if normal < dist[nxt][used]:
                dist[nxt][used] = normal
                heapq.heappush(heap, (normal, nxt, used))
            if not used:
                discounted = cost + edge // 2
                if discounted < dist[nxt][1]:
                    dist[nxt][1] = discounted
                    heapq.heappush(heap, (discounted, nxt, 1))
    return -1 if dist[end][1] == inf else dist[end][1]
```

## Q3. 해설

할인 사용 전과 후는 미래에 할 수 있는 행동이 다르므로 각 도시를 두 상태로 복제합니다. 비용이 음수가 아니므로 확장 그래프에 다익스트라를 적용할 수 있습니다.

- 시간복잡도 `O((V+E) log V)`
- 반례: 비용 1인 도로를 할인하면 0이 됩니다.
- 정확성 근거: 원래 경로에서 할인 시점까지 포함한 모든 선택은 확장 그래프의 경로와 일대일 대응합니다.

## Q4. 문제 — 두 필수 거점

양방향 양의 가중치 그래프에서 1번 도시를 출발해 n번 도시로 갑니다. 중간에 `a`, `b` 두 도시를 모두 방문해야 하며 순서는 자유입니다. 최소 비용을 return 하고 가능한 경로가 없으면 `-1`을 return 하세요. 도시와 도로는 여러 번 지나도 됩니다.

- `2 ≤ n ≤ 100,000`, 도로 최대 200,000개
- 예: `n=4, roads=[[1,2,1],[2,3,1],[3,4,1],[1,4,10]], a=2, b=3` → `3`

## Q4. 정답

```python
import heapq

def solution(n, roads, a, b):
    graph = [[] for _ in range(n + 1)]
    for u, v, cost in roads:
        graph[u].append((v, cost)); graph[v].append((u, cost))

    def dijkstra(start):
        inf = 10**30
        dist = [inf] * (n + 1); dist[start] = 0
        heap = [(0, start)]
        while heap:
            cost, node = heapq.heappop(heap)
            if cost != dist[node]: continue
            for nxt, edge in graph[node]:
                new_cost = cost + edge
                if new_cost < dist[nxt]:
                    dist[nxt] = new_cost
                    heapq.heappush(heap, (new_cost, nxt))
        return dist

    from_one, from_a, from_b = dijkstra(1), dijkstra(a), dijkstra(b)
    route1 = from_one[a] + from_a[b] + from_b[n]
    route2 = from_one[b] + from_b[a] + from_a[n]
    answer = min(route1, route2)
    return -1 if answer >= 10**30 else answer
```

## Q4. 해설

필수 거점 방문 순서는 `1→a→b→n` 또는 `1→b→a→n` 두 가지뿐입니다. 각 구간은 독립적으로 최단 경로를 사용해도 전체 조건을 해치지 않습니다.

- 시간복잡도: 다익스트라 3회, `O((V+E) log V)`
- 반례: 두 후보 중 하나만 가능한 경우와 둘 다 불가능한 경우를 구분합니다.
- 정확성 근거: 임의의 유효 경로를 세 구간으로 나누고 각 구간을 최단 경로로 교체하면 비용은 증가하지 않습니다.
