# 문제

## Q1. 로그 식별자 정리

운영 로그의 식별자에는 영문자, 숫자, 하이픈(`-`), 밑줄(`_`), 공백이 섞여 있습니다. 식별자를 아래 규칙으로 정리한 뒤, **서로 다른 정리 결과의 개수**를 구하려고 합니다.

각 식별자에 다음 규칙을 순서대로 적용합니다.

1. 영문 대문자는 대응하는 소문자로 바꿉니다.
2. 공백, 하이픈, 밑줄은 모두 구분자로 취급합니다. 구분자가 연속해도 하나의 구분자로 봅니다.
3. 구분자로 나뉜 단어들을 비어 있지 않은 순서대로 이어 붙이고, 단어 사이에는 하이픈 하나(`-`)를 넣습니다.
4. 정리 결과의 맨 앞과 맨 뒤에는 하이픈이 없어야 합니다.

식별자 목록 `ids`가 매개변수로 주어질 때, 정리 결과가 서로 다른 식별자의 개수를 return 하도록 `solution` 함수를 완성하세요.

### 제한사항

- `1 ≤ ids`의 길이 `≤ 100,000`
- 각 문자열의 길이는 `1` 이상 `100` 이하입니다.
- 각 문자열은 영문 대소문자, 숫자, 공백, `-`, `_`로만 이루어집니다.
- 각 문자열에는 영문자 또는 숫자가 적어도 하나 포함됩니다.

### 입출력 예

| ids | result |
|---|---:|
| `["Alpha team", "alpha-team", "ALPHA__TEAM", "beta 2"]` | `2` |
| `["  A__B-C  ", "a b c", "a---b___c", "A_B_D"]` | `2` |

### 설명

첫 번째 예시에서 앞의 세 식별자는 모두 `alpha-team`으로 정리되고, 마지막 식별자는 `beta-2`가 됩니다.

## Q2. 쿠폰 적용 구간의 매출 합계

연속한 날짜의 일 매출이 `sales`에 저장되어 있습니다. 마케팅 팀은 여러 구간에 쿠폰을 적용할 예정이며, 각 구간의 매출 합계를 빠르게 확인하려고 합니다.

`queries`의 원소 `[left, right]`는 `sales`의 **1번부터 센** `left`번째 날부터 `right`번째 날까지(양 끝 포함)를 의미합니다.

`sales`와 `queries`가 매개변수로 주어질 때, 각 질의 구간의 매출 합계를 순서대로 담은 배열을 return 하도록 `solution` 함수를 완성하세요.

### 제한사항

- `1 ≤ sales`의 길이 `≤ 200,000`
- `-1,000,000 ≤ sales[i] ≤ 1,000,000`
- `1 ≤ queries`의 길이 `≤ 200,000`
- 모든 `queries`의 원소는 `[left, right]` 형식이며 `1 ≤ left ≤ right ≤ sales`의 길이입니다.
- 정답은 64비트 정수 범위 안에 있습니다.

### 입출력 예

| sales | queries | result |
|---|---|---|
| `[5, -2, 7, 3, -4]` | `[[1, 3], [2, 5], [4, 4]]` | `[10, 4, 3]` |
| `[-10, 10, -10, 10]` | `[[1, 4], [2, 3], [3, 4]]` | `[0, 0, 0]` |

### 설명

첫 번째 예시의 첫 질의는 `5 + (-2) + 7 = 10`입니다.

## Q3. 순찰 로봇의 배송 확인

창고 지도 `warehouse`는 같은 길이의 문자열로 이루어진 배열입니다.

- `S`: 로봇의 시작 위치 (정확히 하나)
- `P`: 아직 확인하지 않은 배송 상자
- `#`: 벽
- `.`: 빈 칸

로봇은 `commands`의 문자를 앞에서부터 하나씩 실행합니다.

- `U`, `D`, `L`, `R`은 각각 위, 아래, 왼쪽, 오른쪽 한 칸 이동을 시도합니다.
- 지도 밖으로 나가거나 벽으로 이동하려는 명령은 무시합니다.
- 로봇이 `P` 칸에 **처음 도착한 순간** 해당 상자를 확인합니다. 한 번 확인한 상자는 다시 세지지 않습니다.

`warehouse`, `commands`가 매개변수로 주어질 때, 모든 명령을 실행한 뒤 확인한 상자의 개수를 return 하도록 `solution` 함수를 완성하세요.

### 제한사항

- `1 ≤ warehouse`의 길이 `≤ 1,000`
- `1 ≤ warehouse[i]`의 길이 `≤ 1,000`
- 모든 `warehouse[i]`의 길이는 같습니다.
- `warehouse`에는 `S`가 정확히 하나 있습니다.
- `warehouse`는 `S`, `P`, `#`, `.`으로만 이루어집니다.
- `1 ≤ commands`의 길이 `≤ 1,000,000`
- `commands`는 `U`, `D`, `L`, `R`로만 이루어집니다.

### 입출력 예

| warehouse | commands | result |
|---|---|---:|
| `["S.P", ".#.", "P.."]` | `"RRDLLD"` | `2` |
| `["S#P", "...", "P#P"]` | `"RRDDLLDDRR"` | `1` |

### 설명

첫 번째 예시에서 로봇은 오른쪽의 상자 하나를 확인한 뒤, 아래와 왼쪽으로 이동해 왼쪽 아래 상자도 확인합니다.

## Q4. 가장 가까운 대피소

도시는 `city`로 표현되는 직사각형 격자입니다.

- `H`: 주민이 있는 집
- `S`: 대피소
- `X`: 지나갈 수 없는 건물
- `.`: 지나갈 수 있는 빈 길

주민은 상하좌우로 인접한 칸으로 한 번에 한 칸 이동할 수 있습니다. 집 또는 빈 길은 지나갈 수 있지만 건물은 지날 수 없습니다. 각 집은 **가장 가까운 대피소까지의 최소 이동 횟수**만큼 이동한다고 할 때, 모든 집의 이동 횟수 합을 구하세요.

어떤 집에서 어느 대피소로도 갈 수 없다면 `-1`을 return 하세요.

`city`가 매개변수로 주어질 때, 조건을 만족하는 값을 return 하도록 `solution` 함수를 완성하세요.

### 제한사항

- `1 ≤ city`의 길이 `≤ 1,000`
- `1 ≤ city[i]`의 길이 `≤ 1,000`
- 모든 `city[i]`의 길이는 같습니다.
- `city`는 `H`, `S`, `X`, `.`으로만 이루어집니다.
- `H`와 `S`는 각각 하나 이상 존재합니다.
- 정답은 64비트 정수 범위 안에 있습니다.

### 입출력 예

| city | result |
|---|---:|
| `["H..S", ".XX.", "H..."]` | `8` |
| `["H.X", "XXX", "S.."]` | `-1` |

### 설명

첫 번째 예시에서 첫 번째 집의 최소 이동 횟수는 3, 두 번째 집의 최소 이동 횟수는 5이므로 결과는 8입니다.

# 해설

## Q1. 로그 식별자 정리

대소문자를 통일한 뒤 공백·하이픈·밑줄을 모두 같은 구분자로 처리합니다. 연속한 구분자는 빈 단어를 만들지 않도록 주의하고, 단어를 `-`로 연결한 결과를 집합에 넣습니다.

- 시간복잡도: 전체 문자열 길이 합을 `L`이라 할 때 `O(L)`
- 핵심 반례: `"__A---B  "`는 `a-b`가 되어야 합니다.

```python
def solution(ids):
    normalized = set()
    for text in ids:
        words, current = [], []
        for ch in text.lower():
            if ch in " -_":
                if current:
                    words.append("".join(current))
                    current = []
            else:
                current.append(ch)
        if current:
            words.append("".join(current))
        normalized.add("-".join(words))
    return len(normalized)
```

## Q2. 쿠폰 적용 구간의 매출 합계

매 질의마다 직접 더하면 최악의 경우 너무 느립니다. `prefix[i]`를 앞에서부터 `i`개 매출의 합으로 두면, 1번 기준 구간 `[left, right]`의 합은 `prefix[right] - prefix[left - 1]`입니다.

- 시간복잡도: `O(N + Q)`
- 핵심 반례: 첫날부터 시작하는 `[1, right]`, 음수 매출, 큰 합계

```python
def solution(sales, queries):
    prefix = [0]
    for value in sales:
        prefix.append(prefix[-1] + value)
    return [prefix[right] - prefix[left - 1] for left, right in queries]
```

## Q3. 순찰 로봇의 배송 확인

시작 좌표를 찾고 각 명령을 한 번씩 실행합니다. 지도 밖 또는 벽이면 현재 위치를 유지합니다. 상자를 확인한 뒤 그 칸을 `.`으로 바꾸면 같은 상자를 여러 번 방문해도 다시 세지 않습니다.

- 시간복잡도: `O(R × C + |commands|)`
- 핵심 반례: 이동이 실패한 뒤 다음 명령은 정상 처리, 한 `P`의 재방문

```python
def solution(warehouse, commands):
    board = [list(row) for row in warehouse]
    rows, cols = len(board), len(board[0])
    r = c = 0
    for i in range(rows):
        for j in range(cols):
            if board[i][j] == "S":
                r, c = i, j

    direction = {"U": (-1, 0), "D": (1, 0), "L": (0, -1), "R": (0, 1)}
    checked = 0
    for command in commands:
        dr, dc = direction[command]
        nr, nc = r + dr, c + dc
        if not (0 <= nr < rows and 0 <= nc < cols) or board[nr][nc] == "#":
            continue
        r, c = nr, nc
        if board[r][c] == "P":
            checked += 1
            board[r][c] = "."
    return checked
```

## Q4. 가장 가까운 대피소

집마다 BFS를 실행하면 같은 길을 반복 탐색합니다. 반대로 모든 대피소를 동시에 큐에 넣고 BFS를 한 번 하면, 모든 칸의 가장 가까운 대피소 거리를 계산할 수 있습니다. 이후 집의 거리만 더하고, 거리 `-1`인 집이 하나라도 있으면 `-1`을 반환합니다.

- 시간복잡도: `O(R × C)`
- 핵심 반례: 대피소가 여러 개인 경우, 건물에 막힌 집, 긴 우회 경로

```python
from collections import deque


def solution(city):
    rows, cols = len(city), len(city[0])
    distance = [[-1] * cols for _ in range(rows)]
    queue = deque()

    for r in range(rows):
        for c in range(cols):
            if city[r][c] == "S":
                distance[r][c] = 0
                queue.append((r, c))

    while queue:
        r, c = queue.popleft()
        for dr, dc in ((-1, 0), (1, 0), (0, -1), (0, 1)):
            nr, nc = r + dr, c + dc
            if not (0 <= nr < rows and 0 <= nc < cols):
                continue
            if city[nr][nc] == "X" or distance[nr][nc] != -1:
                continue
            distance[nr][nc] = distance[r][c] + 1
            queue.append((nr, nc))

    total = 0
    for r in range(rows):
        for c in range(cols):
            if city[r][c] == "H":
                if distance[r][c] == -1:
                    return -1
                total += distance[r][c]
    return total
```
