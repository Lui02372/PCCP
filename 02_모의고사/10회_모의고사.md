## Q1. 문제 — 사용자별 알림 묶음

`messages[i]=[사용자,시각,내용]`입니다. 같은 사용자의 알림을 시각순으로 정렬했을 때, 직전 알림과 시각 차이가 5분 이하이면 같은 묶음에 속합니다. 차이가 6분 이상이면 새 묶음입니다. 사용자 이름 사전순으로 각 사용자의 묶음 수를 return 하세요.

- 메시지 최대 200,000개, 시각은 0 이상 `10^9` 이하
- 같은 사용자의 동일 시각 메시지도 존재 가능
- 예: `[["a",1,"x"],["a",6,"y"],["a",12,"z"],["b",3,"q"]]` → `[2,1]`

## Q1. 정답

```python
from collections import defaultdict

def solution(messages):
    times = defaultdict(list)
    for user, time, _ in messages: times[user].append(time)
    answer = []
    for user in sorted(times):
        ordered = sorted(times[user]); groups = 1
        for i in range(1, len(ordered)):
            if ordered[i] - ordered[i - 1] > 5: groups += 1
        answer.append(groups)
    return answer
```

## Q1. 해설

묶음 시작 시각이 아니라 직전 알림과 비교합니다. 1, 6, 11은 첫 알림과 마지막 차이가 10이어도 하나의 묶음입니다.

- 시간복잡도 `O(N log N)`
- 반례: 차이가 정확히 5분이면 같은 묶음입니다.

## Q2. 문제 — 문서 변경 이력

이벤트 `[문서,사용자,"EDIT"|"DELETE"]`가 입력 순서대로 발생합니다. EDIT는 문서가 없으면 생성하고 있으면 수정하며, 해당 사용자가 마지막 편집자가 됩니다. DELETE는 존재하는 문서를 삭제합니다. 삭제 뒤 EDIT가 오면 새 문서로 다시 생성됩니다. 최종 존재 문서의 마지막 편집 사용자를 문서명 사전순으로 return 하세요.

- 이벤트 최대 300,000개
- DELETE 시점에는 문서가 항상 존재
- 예: `[["a","u1","EDIT"],["a","u2","DELETE"],["a","u3","EDIT"],["b","u4","EDIT"]]` → `["u3","u4"]`

## Q2. 정답

```python
def solution(events):
    documents = {}
    for document, user, action in events:
        if action == 'EDIT': documents[document] = user
        else: del documents[document]
    return [documents[name] for name in sorted(documents)]
```

## Q2. 해설

최종 결과에 필요한 정보는 현재 존재 여부와 마지막 편집자뿐이므로 전체 이력을 보관할 필요가 없습니다.

- 시간복잡도 평균 `O(N + D log D)`
- 반례: 삭제된 문서가 다시 생성되면 삭제 전 편집자는 남지 않습니다.

## Q3. 문제 — 충전소가 있는 탈출 경로

격자에는 시작 `S`, 출구 `E`, 벽 `#`, 길 `.`, 충전소 `C`가 있습니다. 상하좌우 한 칸 이동마다 배터리 1을 소모하며 배터리가 0이면 이동할 수 없습니다. 시작 시 최대치 `capacity`이고, C에 도착하면 이동 비용을 먼저 소모한 뒤 즉시 최대치로 충전됩니다. 최소 이동 횟수를 return 하고 불가능하면 `-1`입니다.

- 행·열 각각 최대 150, `1≤capacity≤20`
- 예: `["S.CE"]`, capacity=2 → `3`

## Q3. 정답

```python
from collections import deque

def solution(board, capacity):
    rows, cols = len(board), len(board[0])
    for r in range(rows):
        for c in range(cols):
            if board[r][c] == 'S': start = (r, c)
    visited = [[[False] * (capacity + 1) for _ in range(cols)] for _ in range(rows)]
    visited[start[0]][start[1]][capacity] = True
    queue = deque([(start[0], start[1], capacity, 0)])
    while queue:
        r, c, battery, distance = queue.popleft()
        if board[r][c] == 'E': return distance
        if battery == 0: continue
        for dr, dc in ((-1,0),(1,0),(0,-1),(0,1)):
            nr, nc = r + dr, c + dc
            if not (0 <= nr < rows and 0 <= nc < cols) or board[nr][nc] == '#': continue
            next_battery = capacity if board[nr][nc] == 'C' else battery - 1
            if not visited[nr][nc][next_battery]:
                visited[nr][nc][next_battery] = True
                queue.append((nr, nc, next_battery, distance + 1))
    return -1
```

## Q3. 해설

같은 좌표라도 남은 배터리가 다르면 미래 이동 가능성이 다릅니다. 모든 간선의 이동 횟수가 1이므로 상태 그래프에 BFS를 적용합니다.

- 시간복잡도 `O(RC×capacity)`
- 반례: 배터리 1로 충전소에 이동하면 도착 즉시 최대치가 됩니다.
- 정확성 근거: BFS가 처음 출구 상태를 꺼내는 시점은 모든 가능한 상태 경로 중 이동 횟수가 최소입니다.

## Q4. 문제 — 마감 작업 보상

`tasks[i]=[duration,deadline,reward]`입니다. 작업은 한 명이 중단 없이 하나씩 수행하며 시각 0에 시작할 수 있습니다. 완료 시각이 자신의 deadline 이하인 작업만 선택할 수 있습니다. 선택한 모든 작업을 마감 내 끝내면서 얻는 최대 보상 합을 return 하세요.

- 작업 최대 2,000개
- duration·deadline은 1 이상 10,000 이하, reward는 1 이상 `10^9` 이하
- 예: `[[2,2,50],[1,2,20],[2,3,100]]` → `120`

## Q4. 정답

```python
def solution(tasks):
    tasks.sort(key=lambda task: task[1])
    max_deadline = max(deadline for _, deadline, _ in tasks)
    dp = [-1] * (max_deadline + 1); dp[0] = 0
    for duration, deadline, reward in tasks:
        for end_time in range(deadline, duration - 1, -1):
            if dp[end_time - duration] != -1:
                dp[end_time] = max(dp[end_time], dp[end_time - duration] + reward)
    return max(dp)
```

## Q4. 해설

선택 작업은 마감시각 오름차순으로 수행해도 됩니다. `dp[t]`는 현재까지 본 작업으로 정확히 t에 끝날 때의 최대 보상입니다. 시간을 뒤에서 갱신해 같은 작업을 두 번 고르지 않습니다.

- 시간복잡도 `O(N×maxDeadline)`, 공간복잡도 `O(maxDeadline)`
- 반례: 보상이 큰 작업 하나보다 짧은 작업 여러 개가 더 유리할 수 있습니다.
- 정확성 근거: 마감순으로 정렬한 선택 집합은 각 작업 처리 시점에 마감 조건을 만족하며, DP는 선택·미선택을 모두 열거합니다.

| 문항 | 제출 전 확인 | 성능 기준 |
|---|---|---|
| Q1 | 직전 알림과 비교, 정확히 5분 포함 | 정렬 `O(N log N)` |
